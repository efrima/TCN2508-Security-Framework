# Ethics Statement

## Purpose

This framework is developed strictly for **educational purposes** as part of the TCN2508 cybersecurity course. It demonstrates offensive and defensive security techniques in a controlled environment.

## Ethical Principles

### 1. Authorization
- **NEVER** use this tool against systems you do not own or have explicit written authorization to test
- All testing must occur within isolated lab environments (VMs, containers, private networks)
- Obtain signed agreements before any testing engagement

### 2. No Harm
- This tool is designed to educate, not to cause damage
- All exploits are limited to proof-of-concept demonstrations
- Defensive modules are central to the framework's design

### 3. Responsible Disclosure
- If vulnerabilities are discovered in real systems during authorized testing, follow responsible disclosure practices
- Report findings to system owners before any public disclosure
- Allow reasonable time for remediation

### 4. Legal Compliance
- Users must comply with all applicable laws and regulations
- Unauthorized computer access is a criminal offense in most jurisdictions
- The authors assume no liability for misuse of this tool

## Prohibited Activities

- Scanning or attacking production systems without authorization
- Using harvested credentials for unauthorized access
- Distributing malware or weaponized exploits
- Any activity that violates computer crime laws

## Acknowledgment

By using this framework, you acknowledge that:
1. You understand the ethical and legal implications
2. You will only use it in authorized lab environments
3. You accept full responsibility for your actions
